<h2 align="left">Hola, soy Gabriel 👋</h2>

Desarrollador backend de España, especializado en Python (FastAPI) con experiencia previa en PHP/Symfony.
Actualmente construyendo APIs REST desde cero para clientes reales, con foco en arquitectura backend, bases de datos y despliegue con Docker.

### 💼 Experiencia

- **Desarrollador Backend (actual)** — Desarrollo de una API REST desde cero para la gestión de un taller mecánico de flotas: FastAPI, MariaDB, SQLAlchemy, Alembic, autenticación JWT, Docker Compose, e integraciones con WhatsApp Business y ERP (Spiga+).
- **Desarrollo Web** — Diseño y desarrollo de páginas web con PHP, HTML y CSS para el sector sanitario.

### 🚀 Proyectos personales
